# Crane Service Management Web App — Specification

This repository contains the specification and instructions for the **Crane Service Management Web App**.

For complete details, see [crane_service_management_spec.md](file:///Users/mac/demo%20crane%20erp/crane_service_management_spec.md).

## Core Modules & Features
- **Dashboard**: Simple business overview with 4 metrics & quick actions.
- **Cranes**: Crane fleet inventory & management.
- **Customers**: Simple customer contact & GST tracking.
- **Invoices**: Tax invoice generation with CGST/SGST/IGST breakdown & printable preview.
- **Payments**: Simple payment state tracker.
- **Settings**: Company info & invoice configuration.
